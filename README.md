# AIM Labs — website

Static site for AIM Labs, the research and innovation division of AIM World.

Run locally:

```bash
python3 -m http.server 5180
```

then open http://127.0.0.1:5180.

- `index.html`, `styles.css` — page and styles
- `hero.js` — hero: AIM film clips with the machine-vision lens
- `sections.js`, `main.js` — interactive sections, header, menu, parallax
- `assets/video/` — clips from the AIM film and per-frame model output (JSON)
- `tools/` — scripts that generate the model data for new clips

Figures, portfolio projects, partners, portraits and notes are placeholders and are labelled as such on the page.
